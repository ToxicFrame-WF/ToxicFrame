# ToxicFrame

A desktop companion app for Warframe.

## Download

Get the latest installer from the [Releases](../../releases) page.

- **Windows:** download `ToxicFrame-Setup-<version>.exe` and run it.
- **Linux:** coming later.

## Features

- Inventory and mastery tracking
- warframe.market prices, buy/sell orders and riven search
- Relic rewards and Void Fissure overlay
- Arbitration schedule and live tracking
- World cycle and Baro reminders

## Privacy

Your warframe.market login token is stored encrypted on your own PC. Nothing is sent anywhere except to warframe.market and the public Warframe data sources the app reads.
